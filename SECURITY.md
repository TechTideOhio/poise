# Security Policy

## Supported Versions

Only the latest release of `poise` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities directly via email to `security@techtideai.io`.
Do not open public GitHub issues for security vulnerabilities.
Reports will receive a response within 48 hours.
